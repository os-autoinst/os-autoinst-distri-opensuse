parse_line

parse_line($string);

This test's chk_rps() helper prints a description padded with 'printf', then appends the status on the same line, e.g.:

# empty rps_default_mask                                     [ ok ]
# changing rps_default_mask doesn't affect existing devices   [fail] expected 1 found 0

The whole test is skipped outright on systems with 2 CPUs or fewer, in which case none of this is ever printed. Lines that do not match this format are returned unchanged.
