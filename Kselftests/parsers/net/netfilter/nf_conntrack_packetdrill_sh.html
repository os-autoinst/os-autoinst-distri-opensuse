parse_line

parse_line($string);

This test prints a description with 'printf' (no trailing newline), then runs packetdrill, whose own diagnostics (if any) land on the same line and on following lines, before a bare 'OK' or 'FAIL' marks the actual verdict, e.g.:

# packetdrill/conntrack_syn_challenge_ack.pkt       (ipv4)                    packetdrill/conntrack_syn_challenge_ack.pkt:38: warning handling packet: ...
# script packet:  0.223897 . 1:1(0) ack 1 win 256 <nop,nop,TS val 1 ecr 1>
# actual packet:  0.213892 . 1:1(0) ack 1 win 1050 <nop,nop,TS val 115 ecr 1>
# OK

or, with no diagnostics, directly on one line:

# packetdrill/conntrack_ack_loss_stall.pkt          (ipv4)                    OK

The subtest name from the last 'packetdrill/... (ipvN)' prefix is kept and used once the bare 'OK'/'FAIL' line shows up. Lines that do not match this format are returned unchanged.
