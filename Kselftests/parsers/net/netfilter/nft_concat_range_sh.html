parse_line

parse_line($string);

nft_concat_range.sh groups its subtests under category headers, and prints each result with a duration instead of the usual 'TEST:' prefix, for example:

# TEST: correctness
#   net,port                              1s                              [ OK ]
#   port,net                              0s                              [ OK ]

The category is kept and prepended to the subtest name (e.g. 'correctness: net,port'), since the same name is reused across categories (e.g. 'reported issues', 'correctness', 'concurrency' and 'timeout'). Lines that do not match this format are returned unchanged.
