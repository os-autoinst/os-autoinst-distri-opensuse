parse_line

parse_line($string);

This test prints a box-drawn table, one row per case, with the result in the last column, e.g.:

│    gre │     4 │     4 │ inherit 0x08 │  inherit 134 │ false │     OK │

Table headers and separator lines don't have 'OK'/'FAIL' in the last column and are returned unchanged, same as the extra diagnostic rows printed below a failing row. This module is saved as UTF-8 without 'use utf8', so the box-drawing character below is matched as its raw byte sequence, same as the unencoded log lines coming from Kselftests::utils::post_process_single().
