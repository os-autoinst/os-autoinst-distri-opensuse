parse_line

parse_line($string);

This test re-invokes itself with the arguments for each combination, echoing them first, e.g.:

# ipv4 udp -m 1 -t 1 -n 32
# cpu: unable to pin, may increase variance.
# tx=83968 (MB=5239), tx/s=83968 (MB/s=5239)
# rx=82045 (5119 MB)
# ok

A failure aborts the script (set -e), so only 'ok' is ever printed. The subtest name from the last 'ipv4|ipv6 ...' line is kept and used once the bare 'ok' line shows up. Lines that do not match this format are returned unchanged.
