lib/Kselftests/parsers/net/psock_snd_sh.pm

parse_line

parse_line($string);

This test echoes a description, then runs the psock_snd binary, whose first action is always 'system("sysctl -w net.ipv4.conf.lo.accept_local=1")', printing 'net.ipv4.conf.lo.accept_local = 1' before anything else, e.g.:

# raw csum_off with bad offset (expected to fail)
# net.ipv4.conf.lo.accept_local = 1
# ./psock_snd: write: Invalid argument
# raw min size
# net.ipv4.conf.lo.accept_local = 1
# tx: 42
# rx: 0
# OK

Cases labelled '(expected to fail)' are wrapped in '(! cmd)' by the script and print no 'OK'; the script uses 'set -e' otherwise, so reaching the next case's sysctl line (or the closing 'OK. All tests passed') proves the previous one behaved as expected. The description is therefore resolved one case late, when its successor starts. An actual, unexpected failure aborts the script and leaves the last case unresolved. Lines that do not match this format are returned unchanged.
