parse_line

parse_line($string);

This test (and route_localnet.sh) announce a subtest with 'echo "run NAME test"', then print a bare 'ok' or 'failed' on its own line once it is done, e.g.:

# run arp_evict_nocarrier=1 test
# ok

The subtest name from the last 'run ... test' line is kept and used once the bare status line shows up. Lines that do not match this format are returned unchanged.
