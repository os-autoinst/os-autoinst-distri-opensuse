parse_line

parse_line($string);

This test echoes a description, then runs the skf_net_off binary, which only ever prints one of three fixed diagnostic lines before a bare 'OK', e.g.:

# filter, fragmented skb (-f) (-F)
# bpf filter enabled
# napi frags mode enabled
# raw recv: 0xabababab
# OK

A one-time 'net.ipv4.ip_early_demux = 0' line (from the sysctl call before the first case) is excluded the same way. Any other line is assumed to be the pending description for the next 'OK'. Lines that do not match this format are returned unchanged.
