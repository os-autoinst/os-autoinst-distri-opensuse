parse_line

parse_line($string);

test_vxlan_under_vrf.sh prints each description with 'echo -n', then appends the status on the same line, e.g.:

# Checking HV connectivity                                           [ OK ]

Lines that do not match this format are returned unchanged. A SKIP status is left untouched rather than converted (see net.pm).
