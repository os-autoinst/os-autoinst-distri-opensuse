check_libgcrypt

return if check_libgcrypt();

Install libgcrypt20 (and libgcrypt20-hmac where it still exists) and check that they are at least 1.9.0, see poo#107509. Returns 1 when a Public Cloud BETA image is ahead of its repositories (bsc#1199312) and the test should be aborted, otherwise 0.
