find_whitelist_entry

find_whitelist_entry($env, @test_keys);

Walk the whitelist hash following @test_keys, from the least to the most specific (for example: collection, parent test, subtest). All but the last key must match exactly; the last key (the leaf) is then looked up directly, or, failing that, matched against a '*' entry's test regex at whichever level the walk stopped. This allows a whitelist file to nest entries to an arbitrary depth, with the '*' wildcard always scoped to the most specific level reached.
