qesap_get_public_cloud_tags

my %tags = qesap_get_public_cloud_tags();

Calculate tags to match CloudCustodian needs. Return a dictionary.

openqa_created_date is the creation time used by the CloudCustodian cleanup policies (value_type: age, key: tag:openqa_created_date). The value is in ISO 8601 basic format with an explicit UTC designator, e.g. 20261110T030612Z:

  • CloudCustodian parses it with dateutil. A value without a timezone is read as the local time of the CloudCustodian host. A value it cannot parse is never matched, so the resource is never cleaned up.

  • The value uses only characters valid in tag values.

  • The basic format has no - date separators, so YAML 1.1 parsers keep it as a string. The extended format (2026-11-10T03:06:12Z) is converted to a date and written back with a space, which the tag validation of the deployment rejects.
