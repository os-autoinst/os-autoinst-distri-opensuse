_get_command_line_size

_get_command_line_size()

Returns the COMMAND_LINE_SIZE value for the current worker architecture from COMMAND_LINE_SIZE_BY_ARCH. Dies if the architecture is not supported.

check_kernel_arg_len

check_kernel_arg_len()

Validates whether the length of the longest kernel command line found in /boot/grub2/grub.cfg exceeds the architecture-specific COMMAND_LINE_SIZE limit defined in COMMAND_LINE_SIZE_BY_ARCH.
